Material Parameters

Define the material-level knobs once, then let the platform regenerate derived inputs.

idle

Setup is where you check the material type, k-mesh, spin option, and MAGMOM. If you are unsure, review the visible fields and click `Save Parameters`.

Pick a precision level. It fills in the k-point meshes below from the shape of your cell, and the plane-wave cutoff from your POTCAR.

Every level here is an unconverged starting point, including High. Run the Converge stage on your own system before you report any number.

Material presets (fixed parameter sets for common material types)

Presets apply one fixed parameter set regardless of your cell size. Precision levels above adapt to your structure instead.

Bulk = normal 3D crystal. 2D/slab = vacuum along one direction. Molecule = isolated cluster in a box.

Use `PBE/PBEsol` for structure steps. `HSE06` is supported for heavier electronic-structure refinement; hybrid `band` will reuse the SCF mesh as runtime `KPOINTS` and the saved line path as runtime `KPOINTS_OPT`.

A precision level fills these in from the cell. Left empty, the DOS mesh falls back to a slightly denser version of the SCF mesh (roughly `+2` per axis, capped at `31`).

This post-processing q-mesh is used only for phonon DOS / PDOS and is independent from the VASP supercell displacement mesh.

These are starting moments used to initialize the SCF, not predicted moments. VASP will relax them; check the final moment in the output.
